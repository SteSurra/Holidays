## Rules

Policy chosen for traveler UX on **Solo gratis**: **Public-open** (option 2).

- **free** — official venue or official city/tourism (GO TOKYO, JNTO, municipal, etc.) describes open public access to the main visit area (shrine precinct, street, district, park approach) and does **not** state an entrance / admission / 拝観料 / 入場料 requirement for that main visit. Voluntary offerings / goshuin do not count as paid.
- **paid** — the main visit needs a ticket or mandatory fee (including a “symbolic” mandatory fee).
- **mixed** — same place has a documented free main area **and** a documented paid sub-area (museum, treasure hall, inner garden, observatory, boats, etc.). Shows under both Solo gratis and Solo a pagamento.
- **pending** — leave `admission` unset when sources conflict, access is unclear, the item is a `guide-map-visit-*` synthetic without a persistable row, or it is a curated no-venue generic activity (no single official admission page). The UI filter must not claim free/paid for those cards.
- **Closeout** — after C1–C7, every normal curated place/experience pipe row must have `free|paid|mixed`. Structural pending that may remain: all `guide-map-visit-*` synthetics + the explicit no-venue allowlist in `scripts/check-guide-integrity.mjs` (karaoke, kintsugi, street kart, Kyoto tea/yuzen/sake/pottery generics, Hiroshima kyudo, Miyajima momiji workshop). Do not invent admissions for those.
- **No yen** — evidence may quote access wording, never amounts.
- **Source priority** — (1) official venue / operator, (2) municipal / prefectural / JNTO / GO TOKYO tourism, (3) third-party guides only as a lead, never sole proof.
- **Forbidden as sole proof** — tip/booking prose already in the guide, Wikimedia, bare category defaults with no official open-access description.
- **Date note** — do not use ISO `YYYY-MM-DD` in this tree; prefer `YYYY-MM` or prose months for `checkedAt`.
- **When unsure** — keep pending; prefer paid over guessing free if the only ambiguity is a seasonal free window on an otherwise ticketed visit.

Regenerate scaffold (preserves nothing — edit this file by hand after research, or re-dump only before filling):
`node scripts/dump-admission-ledger.mjs`
